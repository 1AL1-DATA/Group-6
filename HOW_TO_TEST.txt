How to test the app:
Setup (Conda - Recommended):
    cd Group-6
    conda env create -f environment.yml
    conda activate group6

Via CLI (terminal)
    cd Group-6
    python3.10 repoguard_cli.py scan vuln_app.py
Options:
# Scan current directory
    python3.10 repoguard_cli.py scan .
# With LLM analysis
    python3.10 repoguard_cli.py scan vuln_app.py --llm
# Scan specific file
    python3.10 repoguard_cli.py scan vuln_app.py
# Scan code string directly
    python3.10 repoguard_cli.py code 'os.system(user_input)'
Via Jupyter Notebook
1. Open Group-6/test_notebook.ipynb in PyCharm
2. Run cells with Shift+Enter
Via Python Code
    import sys

    guard = RepoGuard(use_llm=False)
